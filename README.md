# Zip Game 2

A Java-based application/game that utilizes state management and local database storage.

## Features
- **Core Gameplay**: Powered by Java standard libraries.
- **State Management**: Robust handling of current game state (`GameState.java`).
- **Data Persistence**: Uses a local database to save, load, and manage high-scores/player entries securely (`DatabaseManager.java`).

## Requirements
- Java 17+

## How to run
- Windows: Run `run.bat`
- Linux/Mac: Run `./run.sh`
